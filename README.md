# InboxOrchestrator AI (Frontend)

Unified Multi-Model Intelligence System for Automated Email Understanding, Task Structuring, and Workflow Orchestration.

---

## 🚀 Overview

InboxOrchestrator AI Frontend is a Next.js-based web application that transforms unstructured email communication into structured insights, actionable tasks, and intelligent summaries.

It integrates with a FastAPI backend and Gmail API to provide:
- Email classification
- Task extraction
- Priority detection
- Risk/phishing analysis
- Automated email organization

---

## 🧠 Tech Stack

- Next.js (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Axios (API communication)
- React Hook Form + Zod (forms & validation)
